# 淘宝用户行为数据分析

> 作者：兰茗贺　|　技术栈：Python（Pandas / Matplotlib / Seaborn）
> 数据周期：2014-11-18 ~ 2014-12-18（31 天）

## 一、项目背景

电商平台的核心目标是"让更多访客完成购买、让买过的人反复购买"。本项目基于淘宝真实用户行为日志，围绕**流量转化、用户留存、复购、用户分层、活跃规律、商品类目**六条主线，定位经营中的流失环节与高价值人群，输出可落地的运营动作。

## 二、数据说明

- **数据来源**：阿里巴巴天池公开数据集 UserBehavior（淘宝用户行为日志）
- **字段**：user_id（用户）、item_id（商品）、behavior_type（1点击 / 2收藏 / 3加购 / 4支付）、item_category（类目）、time（时间）
- **样本规模**：按用户随机抽样 128.5 万行，清洗去重后 **65.8 万条**有效记录、**1,019 个用户**、**5,971 个类目**，覆盖 31 天

## 三、项目文件（按执行顺序）

| 文件 | 作用 |
|------|------|
| `第一步 数据检查去重与清洗.py` | 读取原始数据，类型转换、时间解析、去重，输出 clean.csv |
| `python版 第二步 漏斗分析.py` | 点击→加购→支付转化漏斗，算各层转化率 |
| `python版 第三步 留存分析.py` | 次日/3/7/14/30日留存，含观测窗口修正 |
| `python版 第四步 复购率.py` | 支付用户复购率、人均支付天数 |
| `python版 第五步 RFM用户分层.py` | R+F两维打分（无金额字段），5类人群分层 |
| `python版 第六步 活跃时段分析.py` | 24小时规律、工作日vs周末、一周各天 |
| `python版 第七步 商品与类目分析.py` | 类目TOP、帕累托二八、高加购低转化问题类目 |
| `图表.py` | 一次性生成 11 张分析图表，存到 charts/ 文件夹 |
| `excel.py` | 自动生成多 sheet Excel 报表（我的报表.xlsx） |
| `clean.csv` | 清洗后的数据（65.8万行） |
| `我的报表.xlsx` | Excel 自动化报表 |
| `charts/` | 11 张分析图表 |
| `分析报告.md` | 完整图文分析报告（含问题—结论—动作闭环表） |

## 四、核心结论

| 模块 | 核心指标 |
|------|---------|
| 转化漏斗 | 加购率 5.89%、点击→支付 1.87%、加购→支付 31.75% |
| 购买渗透率 | 31天内 88.91% 用户至少买过一次（用户口径） |
| 留存 | 次日 71.39% / 3日 68.31% / 7日 67.26% |
| 复购 | 复购率 88.52%，人均支付 5.78 天 |
| RFM分层 | 重要价值客户 40.24%、待挽留 22.47%、潜客 11.09% |
| 活跃时段 | 支付高峰 21 点，支付率最高 10 点 |
| 类目 | 前 10.1% 类目贡献 80% 支付，15 个高加购低转化问题类目 |

## 六、口径说明

- **双口径漏斗**：事件口径（每100次点击的支付数1.87%）衡量流量效率；用户口径（31天内买过的用户占比88.91%）称购买渗透率，衡量用户覆盖，二者不矛盾。
- 本数据为**用户行为日志，不含金额与退款字段**，GMV、客单价、ROI无法计算。
- RFM 中 M（金额）维度缺失，采用 R+F 两维分层，未支付用户单列为潜客。
- 数据采集于 2014 年，绝对数值不代表当前水平，但分析方法与指标口径在当下电商数据工作中完全通用。
